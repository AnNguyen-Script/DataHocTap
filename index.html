Hướng Dẫn Sử Dụng & Triển Khai GitVault

1

Chuẩn bị GitHub Repository

Tạo một kho lưu trữ mới trên GitHub (có thể đặt là Public để ai cũng xem được tệp hoặc Private nếu muốn bảo mật).

  • Vào github.com/new
  • Đặt tên repository (Ví dụ: my-cloud-storage)
  • Tích chọn Add a README file để khởi tạo nhánh main
2

Tạo Personal Access Token (PAT)

Token là chìa khóa để trang web có thể ghi, sửa, xóa dữ liệu vào Repository của bạn một cách an toàn:

  • Vào Settings > Developer Settings > Personal access tokens > Fine-grained tokens
  • Bấm Generate new token
  • Chọn Repository access: Only select repositories > Chọn repo vừa tạo
  • Tại mục Permissions > Repository permissions, cấp quyền Contents: Read and write
  • Copy mã Token và dán vào phần Cấu hình Repo trên trang web này
3

Công khai Web trên GitHub Pages (Free 100%)

Để xuất bản trang web này ra internet để bất kỳ ai cũng có thể truy cập:

  • Đẩy source code của trang web này lên GitHub Repository của bạn
  • Vào tab Settings > Pages trong repo của bạn
  • Tại mục Build and deployment > Source, chọn Deploy from a branch > Nhánh main (hoặc /root)
  • Bấm Save. Sau 1 phút, trang web sẽ online tại: https://username.github.io/repo-name
4

Bảo Mật & An Toàn Dữ Liệu

Token của bạn được lưu cục bộ trong trình duyệt của bạn (LocalStorage) và không bao giờ gửi qua bất kỳ máy chủ bên thứ ba nào. Mọi thao tác đều giao tiếp trực tiếp tới API chính thức của GitHub (api.github.com).
